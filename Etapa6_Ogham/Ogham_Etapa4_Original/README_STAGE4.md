Ogham - Etapa 4 (Projeto NetBeans) - Configurado para MySQL localhost

Instruções:
1. Importe script.sql no MySQL Workbench para criar o schema `oghamdb` e dados de teste.
2. Verifique que o MySQL está rodando em localhost e que o usuário 'root' tem senha '1888' (configurado no DBConnection.java).
3. Adicione o driver JDBC (mysql-connector-java) às libraries do projeto no NetBeans.
4. No NetBeans, crie um novo projeto Java e copie a pasta src/ para a pasta 'Source Packages' do projeto (ou abra diretamente como projeto Ant se preferir).
5. Execute a classe app.AppMain.
